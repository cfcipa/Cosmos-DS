# Cosmos DS · MUI

Tema MUI de Cosmos (paquete **Azul**, fuente `ThemeCOSMOS.json` sincronizada desde Figma) y el **kit de IA**:
los componentes aprobados en el lienzo «Asistente Cosmos», reconstruidos sobre MUI Material.

- **Marca** = `src/theme/*` (colores, tipografía, formas, sombras y overrides de MUI). No se edita a mano: viene de Figma.
- **Kit IA** = `src/ai/*`. Solo lee el tema (`palette.ai` se deriva de la marca con `withAiKit`), nunca trae colores propios.
- Íconos: **Lucide** (`lucide-react`).

## Catálogo

El orden sigue el catálogo *Elements* de assistant-ui.

| Sección | Componentes | Estado |
|---|---|---|
| Reasoning | Reasoning | pendiente |
| Messages | UserMessage, AssistantMessage, ActionBar, EditComposer | pendiente |
| Tool use | — | pendiente |
| Knowledge | Sources, Followups | pendiente |
| Composer | Composer (default / compact / pill), Attachment, ContextChip, StarterSuggestions | pendiente |
| Thread | Thread, Disclaimer | pendiente |
| AUI connected | **Tool fallback** (ToolCall + aprobación), **Tool group** | ✅ en MUI |
| Sinco | AssistantSurface, SurfaceHeader, Trigger, ResponsePreview, InlinePrompt, AiMark | pendiente |

## Uso

```tsx
import { CosmosProvider, ToolCall } from '@sinco/cosmos-ds';

<CosmosProvider mode="light">
  <ToolCall toolName="confirmar_facturas" status="complete" durationMs={1240} />
</CosmosProvider>
```
